动词类别与基本形式

动词活用速查

先辨认词典形属于哪一类，再拆成「词干 / 音变 / 助动词」。形式名称不等于句中意义，仍要看上下文。

五段动词

词尾在ア・イ・ウ・エ・オ各段变化。例：呼ぶ → 呼ばない / 呼びます / 呼べば / 呼ぼう。

て・た形会发生音变：う・つ・る → って；む・ぶ・ぬ → んで；く → いて；ぐ → いで；す → して。行く的て形是例外「行って」。

上一段 / 下一段动词

词干保留，去掉词尾「る」后接形式。上一段词干末音在イ段，如見る → 見ない / 見て。下一段末音在エ段，如覚める → 覚めない / 覚めて。

以「いる / える」结尾不一定是一段：切る是五段。要查词典类别，不能仅凭末尾猜测。

カ变 / サ变

来る（カ变）：来ない（こない）/ 来ます（きます）/ 来て（きて）。する（サ变）：しない / します / して。歌词的「気がする」就在这一类。

接在动词后面的部分

「た」表示过去或完成；「ている」常表示持续或结果状态；「ます」表示礼貌；「くれる」把动作放在说话者受益的视角。拆开后再组合理解。
